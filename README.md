
# Bagus Store
### Tugas Latihan Mandiri Flutter - Pertemuan 3

Aplikasi Bagus Store dibuat menggunakan Flutter untuk memenuhi tugas latihan mandiri pada Pertemuan 3. Aplikasi ini menerapkan navigasi antarhalaman, pengiriman data, named routes, dan BottomNavigationBar.

## Fitur Aplikasi

### 1. Push & Pop Navigation
- Halaman Beranda
- Halaman Tentang
- Navigasi menggunakan `Navigator.push()` dan `Navigator.pop()`

### 2. Mengirim Data
- Menampilkan daftar produk
- Memilih produk untuk membuka halaman detail
- Menampilkan nama dan harga produk pada halaman detail

### 3. Named Routes
- Menggunakan named routes untuk navigasi halaman
- Mengirim argumen ke halaman tujuan

### 4. Bottom Navigation Bar
Terdapat tiga menu utama:
- Beranda
- Cari
- Profil

### 5. Menambahkan Produk
- Menambahkan produk baru
- Mengisi nama produk
- Mengisi harga produk
- Menambahkan URL gambar produk

## Teknologi
- Flutter
- Dart
- Android Studio

## Cara Menjalankan Aplikasi

1. Clone repository ini:
   ```bash
   git clone https://github.com/bagussetyonugroho/-Tugas-Latihan-Mandiri-Pertemuan-3.git
   ```

2. Masuk ke folder project:
   ```bash
   cd -Tugas-Latihan-Mandiri-Pertemuan-3
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Jalankan aplikasi:
   ```bash
   flutter run
   ```
